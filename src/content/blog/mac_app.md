# 系统工具效率
- Alfred
置顶，比spotlight高效，支持各种插件，没有上限
- brew
软件包管理工具，要装啥`brew install xxx`就好了
- Appcleaner
mac卸载软件就靠它，一键拖入，彻底清理干净。`CleanMyMac`、`Dr.Cleaner`还收费，笑死人
- istate menus
监控你的电脑，cpu、内存、网络、硬盘，你能想到的都有了
- Handshaker
老罗确实改变了世界，锤子出品必属精品，mac和手机连接的神器，有线和无线均可，Android和iPhone都可以用，itunes是个啥？？？
- Duet
Windows可以用这个把ipad变为第二个屏幕，超好用，支持无线连接，Mac下`mac os 10.15`还是用自带的随航(Sidecar)，延迟更低一些
- Parallel Desktop
Mac下的虚拟机，比`vitural box` `VMware`好用太多
- 外接屏幕开启Retina(Hidpi)
[一键命令行](https://github.com/xzhih/one-key-hidpi/blob/master/README-zh.md)

# 应用效率工具

- 坚果云
最好用的网盘，已经入了4年个人专业版会员，用来多终端同步工作资料，不要太方便
- 休息一下
20min提醒你休息一下眼睛，坐办公室挺需要的
- [WGestures2](https://www.yingdev.com/projects/wgestures)
类比`mac os` 自带触发角，用起来爽飞了，这是一款加强版的应用，装饰键 + 手势，自定义
- Anydesk
即开即用的轻量化远程协助工具，`teamviewer`还要注册账号，还经常被怀疑商用
- Etcher
U盘刻录工具，大佬都在用
- Blackmagic Disk Speed Test
磁盘测速，mac下都用这个，baseline一样，参数对比才有意义
- CleanMyMac
mac下的鲁大师，虽然mac不用怎么管理，也没中过病毒，硬盘小的话，可以用来清垃圾什么的
- DaisyDisk
清理电脑磁盘必备，可视化做的很不错
- Folx
挺好用的下载管理工具
- Transmission
种子下载下载
- μ torrent
种子下载工具
- kaka
压缩包工具
- Mosaic
比Magnet定制程度高，实现windows下`win + →`等功能
- ~~Wechat 小助手~~（被官方封了，缅怀）
远程控制mac、免认证登录、消息防撤回、AI自动回复等功能，还有主题
[wechat-plugin](https://github.com/MustangYM/WeChatExtension-ForMac)
- Wechat 小助手自动更新
微信版本更新后，会删除小助手，这个命令行工具，可以帮你开机自检，微信更新后，自动安装助手
[oh my wechat](https://github.com/lmk123/oh-my-wechat)
- Notion 
神器，添加各种服务，项目管理、笔记、备忘，All-in-one workspace



# 音视频工具
- Downie
它支持1000+网站视频下载，包括YouTube、B站等，而且可以设置4K分辨率下载，几乎无所不能，绝对的神器
- Permute
通用格式转换软件，包括视频、音频，图片乃至pdf，不仅效率高，而且完美配合downie、iTunes，可以连接Downie使用
- IINA
最好用的视频播放器，轻量、简洁、支持云播放、字幕在线搜索
- Adobe Zii
Adobe全家桶都可以通过它来白嫖，再说就说多了
- Picgo
支持多家图床(github、阿里、七牛、腾讯、smms、imgur等)的管理工具
- Pixelmator Pro
mac下的Photoshop，300Mb，比ps轻量，功能足够且易用
- VideoGif
功能如其名，快速视频转gif工具，支持简单的尺寸和时间轴编辑
- PicGif
功能如其名，快速图片转gif工具，win下美图秀秀就挺好😂
- imageOptim
快速压缩图片用，支持Terminal Command`imageoptim image_url`
- Inpaint
快速图片除背景
- remove.bg
快速图片除背景
- iShot
截长图工具，还有很多其他截图功能
- sip
快速获取屏幕上颜色，输出可以是各种格式

# 阅读与写作
- SCI hub
必须置顶，配合`google scholar`下文献效率提升100倍是有的
- texpad
mac下`latex`写作工具，支持`live edit`模式，好用，谁用谁知道系列
- Mweb
mac下`markdown`编辑器，个人感觉最好用，自带图床插件，发布`blog`效率不要太高
- skim
最清凉的pdf预览工具，可以配合`atom` `vs code`实现latex的pdf预览，开大体积pdf超快
- PDF Expert
Mac下的`adobe acrobat`，
- caj viewer
知网文献打开必备，其实还有一个网址可以下载pdf版的知网文献，私信获取
- Mendeley
`Zotero`、`Endnote`也挺好，各有所长吧，习惯了一个就行
配合坚果云使用更佳，毕竟免费的云同步不挂代理，有点慢
- Mathpix snipping tool
latex 公式 OCR 最强软件，准确率一流，识别完自动复制，多种样式任你挑选
- copy translator
整合了`google` `baidu` `bing` 翻译的英文文献阅读工具
- Reeder
RSS阅读管理工具，订阅阅读，不用看广告了
- PDF Squeezer
pdf压缩工具，有一个网站也挺好用的
- small pdf
就是上面说的那个网站，功能齐全，免费有次数限制
- [知网海外版](https://oversea.cnki.net/index/)
可以下载pdf，不用再用`caj viewer`看了
